# Contributing

## Development

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
npm run preview
```

## Code Style

- TypeScript strict mode
- Functional components
- Tailwind CSS for styling
- Lucide React for icons

## Adding Content

Edit files in `src/data/` to update portfolio data.
All data is strongly typed via `src/types/index.ts`.
